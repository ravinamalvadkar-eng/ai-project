# Telecom Customer Churn Prediction

## 📌 Project Overview

This project predicts customer churn in the telecommunications industry using Machine Learning.

The project uses customer subscription and service data to identify customers who are likely to leave the company.

## 🎯 Objective

- Predict whether a customer is likely to churn
- Identify important factors affecting customer churn
- Help businesses take preventive actions to retain customers

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Machine Learning

## 🤖 Machine Learning

The project uses supervised machine learning techniques for customer churn prediction.

### Steps:
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Churn Prediction

## 📊 Project Files

- `python.py` – Python source code
- `telecom_churn_prediction_report.html` – Project report
- `README.md` – Project documentation

## 📈 Results

The model analyzes customer information and predicts customers who are at higher risk of churn.
