1. Problem Statement & Objectives

In the highly competitive telecommunications sector, acquisition costs for new subscribers are estimated to be 5 to 7 times higher than retention costs for existing customers. Customer turnover ("churn") directly undermines recurring revenue streams and lowers long-term Customer Lifetime Value (CLV).

The objective of this project is to build an end-to-end Machine Learning pipeline capable of predicting customer churn probability with high recall. By identifying high-risk churn candidates ahead of renewal cycles, retention teams can deploy targeted promotional offers to mitigate account attrition.

2. Dataset Description

The evaluation utilizes the standardized Telecom Churn Dataset containing 7,043 customer accounts and 20 operational variables capturing demographic, service subscription, and financial transaction metadata.

3. Data Preprocessing Pipeline

1. Missing Value Imputation

The TotalCharges attribute contained 11 blank strings corresponding to new subscribers (Tenure = 0). These were converted to numeric float values and imputed using median strategic values based on Contract type groupings.

2. Categorical Encoding

Binary nominal features (e.g., PaperlessBilling, Partner) were mapped to binary integers (0/1). Multi-class nominal variables (e.g., Contract, PaymentMethod) were transformed using One-Hot Encoding.

3. Feature Scaling

Continuous features (Tenure, MonthlyCharges, TotalCharges) were normalized using StandardScaler to center values around zero with unit variance, preventing magnitude bias during tree splitting.

4. Outlier & Imbalance Management

Interquartile Range (IQR) filtering verified zero destructive extreme outliers. Class imbalance (26.5% positive churn) was handled during training using Synthetic Minority Over-sampling Technique (SMOTE).

5. Model Building & Training

A Random Forest Classifier ensemble architecture was selected due to its robustness against overfitting, implicit feature interaction handling, and high interpretability.

Hyperparameter Calibration (GridSearchCV 5-Fold Cross Validation)
  • n_estimators: 200 decision trees
  • max_depth: 12 levels (tuned to limit tree variance)
  • min_samples_split: 5 samples per internal node
  • criterion: Gini Impurity
  • class_weight: 'balanced' (for minority retention adjustment)

In churn modeling, Recall is the critical optimization metric to minimize False Negatives (unidentified churning customers). The Random Forest model achieves a 79.2% Recall, successfully capturing ~8 out of 10 churning customers prior to account cancellation.

7. Strategic Recommendations

  • Proactive Renewal Offers: Target Month-to-Month accounts reaching month 5 of tenure with discounted 12-month contract upgrade incentives.
  • Fiber Tech Support Bundling: Include 90 days of complimentary Technical Support for new Fiber Optic activations to reduce initial friction.
  • Automated Payment Transition: Offer a $2/month account credit for switching from manual check payments to automated credit card billing.

8. Conclusion & Project Limitations

The implemented Random Forest classification model effectively transforms raw customer telemetry into actionable retention indicators. However, project limitations include:

  1. Lack of Dynamic Behavioral Features: The dataset relies on static snapshots rather than time-series usage trends (e.g., call drop frequencies or data usage spikes).
  2. Unobserved External Variables: Competitor pricing promotions and regional coverage quality metrics were not available in the public feature set.
